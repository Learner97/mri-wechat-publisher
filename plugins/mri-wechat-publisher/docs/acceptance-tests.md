# 第一阶段验收测试

## 本地测试

- [ ] 示例 JSON 通过结构校验。
- [ ] 缺失“研究速览、引言、方法、结果、结果解读、结语”任一必需章节时校验失败。
- [ ] 单篇论文标题未严格使用唯一的“期刊全名或公认缩写 | 内容主标题”结构（包括出现多个 `|`）时校验失败。
- [ ] ` | ` 后的内容主标题超过 20 个字符时校验失败；期刊标识和分隔符不计入这 20 个字符。
- [ ] 标题首尾存在空白或标题包含换行时校验失败，且运行结果与 JSON Schema 一致。
- [ ] 完整标题超过微信字段上限 64 个字符时校验失败。
- [ ] `cover` 存在时缺少 `path`、`alt` 或 `source_note` 任一字段，或本地封面文件不存在时校验失败。
- [ ] 未记录 DOI 或来源标识时校验失败。
- [ ] `publish`、`freepublish` 或 `mass_send` 自动动作被拒绝。
- [ ] HTML 不包含脚本、表单、事件属性和外链样式表。
- [ ] 输出包含标题、研究速览、必需章节和参考文献。
- [ ] `schema_version=8` 新文章严格使用“研究速览、引言、方法、结果、结果解读、结语”，并拒绝独立“方法启示”；有依据的方法认识只能并入结语。
- [ ] 研究速览灵活概括研究问题、对象、分析框架和主要发现，不要求固定字段或字数；其中出现具体 t、p、OR、β 等检验统计量时校验失败。
- [ ] digest 先依据论文内容选择阅读入口，直接陈述、反差、观察、开放问题和自问自答均可，问句不作为默认；研究速览交代怎么做和发现什么，两者不重复同一串样本、模态、步骤与结果事实。
- [ ] 同一批次的 digest 已并排检查；不会全部使用问句，也不会重复“如果……吗”“究竟是……还是……”或固定的“第一句提问、第二句回答”骨架，陈述式灰框同样无批量同构。
- [ ] `method_map` 按 `core`、`supporting`、`routine` 标记重要性，并记录输入数据、处理步骤、统计检验和研究材料定位；输出字段允许按理解需要省略。
- [ ] `method_map.section_heading` 与方法正文中的客观小标题对应，内部字段不进入公开HTML。
- [ ] 软件版本、参数、样本划分、矩阵维度和重采样次数均可定位至研究材料；未报告信息不由默认值或领域惯例补齐，也不默认写入正文。
- [ ] 方法正文突出核心分析的输入、逻辑、关键步骤和决定性参数；完整软件与参数细节保留在 `method_map`，不扩写成命令或参数清单。
- [ ] 同一方法段连续堆积软件名、算法、步长、流线长度、流线数量和其他非关键设置时进入人工复核。
- [ ] 核心与创新方法比标准预处理、常规数据库富集和次要敏感性分析获得更多有效技术细节。
- [ ] 正文不出现“补充材料显示”“proof记录”“来源材料未说明”等内部材料核查过程；版本差异影响结果时只说明实质差异。
- [ ] 正文不出现“该模块”“本模块”“该步骤输出”“分析链”“证据链”等技术报告式元语言。
- [ ] 常规“未报告”“未进一步说明”表述在没有 `critical_missing_details` 时被拒绝。
- [ ] `schema_version=1` 至 `schema_version=7` 历史文章仍可校验和渲染，但新成稿流程不会继续生成旧结构。
- [ ] 引言长于方法或结果、结果占比较低或结语与研究速览篇幅差异较大时，章节统计仍正常报告，但不会仅凭比例阻断或警告。
- [ ] 结语中的“突破性”“重大创新”“首次证明”和证据排名表述被拒绝。
- [ ] 单段结语能够通过；“研究设计上的启发在于”“对MRI研究，较有用的是”等固定方法启示开头被拒绝。
- [ ] HTML调用原始设备系统字体栈，不包含 `@font-face` 或远程字体；系统字体文件不会进入插件，封面继续使用登记的 Noto Sans SC。
- [ ] `digest` 进入草稿元数据，并在作者行与正文“研究速览”之间以浅灰色导读卡准确渲染一次。
- [ ] 同一小标题下没有由相同分析目标拆出的连续短段落；段落数量只作诊断，不作为固定门槛。
- [ ] 仅负责引出下一分析的短过渡句已并入后续实质段落。
- [ ] “不等同于”“不能转换为”“不能覆盖”等纠正式限定语未在结果中反复出现；必要范围说明在结果解读中通过具体数据关系表达。
- [ ] 结果小节数量不受固定值限制；“关键结果”“证据一”等泛化结果小标题被拒绝。
- [ ] 新文章的每条 `evidence_map` 记录都区分直接结果、作者解释、编辑说明或有限延伸，分类不在正文中显示。
- [ ] “本文只需记住”“一句话收束”“真正值得带走的是”“读者”等模板化或直接称呼表达被拒绝。
- [ ] 不再按 11,000 字或固定配图数量发出篇幅超限警告；章节比例只作为重点失衡诊断。
- [ ] 仅阅读标题、研究速览、结果小标题和结语即可判断研究对象、核心方法与主要发现，否则人工 QA 阻断。
- [ ] 结果段只保留决定主要结论成立与否的统计量；同一段连续出现多个 p、OR、β 等统计量时进入人工复核。
- [ ] 结果解读不逐句重复结果；出现完全重复的实质句时校验失败。
- [ ] 结果解读的实质段落增加结果关系、分析层级区分、来源支持的机制解释或必要澄清，不以重复结果或局限清单代替解释。
- [ ] 没有登记为中心结论必要缺失信息时，“未测量”“未纳入”“没有检验”等未实施分析清单被拒绝；实际阴性结果不受影响。
- [ ] 同一结果解读段落集中出现多个否定或限制性表达时进入人工复核，优先改写为实际变量、数据来源和分析定义。
- [ ] “这些结果共同表明”“这一发现进一步说明”“值得注意的是”“总体而言”“这一发现提示我们”“提供了新的视角”等模板用语会进入人工复核，而不是被自动替换为同义词。
- [ ] 相关分析、空间对应、PLS和基因富集与“导致”“驱动”“证明了”“机制证据”等措辞同时出现时进入因果强度复核。
- [ ] 每段末句若只是重复、评价、升华、列举未实施分析或泛泛展望，会被提示优先删除。
- [ ] 对现有稿件做局部修改时，用户未授权修改的前置章节通过内容指纹保持不变。
- [ ] 使用 `validate_article.py <article.json> --baseline <pre-revision-article.json>` 时，任何对前四个受保护章节的改动都被阻断；局部任务只修改结果解读或结语可以通过。
- [ ] 每张版本8图片声明 `mobile_display.strategy`；信息过密的组合图使用裁切、拆分或关键面板策略，并保留原图号和面板标签。
- [ ] 公开HTML只显示简洁图注，不显示图片来源或许可长句；来源、许可和移动端策略仍保留在结构化数据和QA记录中。
- [ ] HTML不包含已登记之外的字体或商业字体名称；封面字体文件、SHA-256和SIL OFL 1.1许可证均可核验。
- [ ] 旧 JSON 状态可一次性迁移到 SQLite，迁移后完整性与外键检查通过。
- [ ] 同一时刻只能存在一个活动周期；已选择论文、5轮冷却候选和重复任务运行键被拒绝。
- [ ] 未选论文在后续5个推荐轮次不可再次出现，并可在第7轮（间隔5轮后）重新进入候选。
- [ ] `select-order --choices 2,3` 按指定顺序建立队列，前一篇保存草稿后自动激活下一篇。
- [ ] 排队论文在 `available_at` 之前返回 `queued_not_ready`，不会因09:30每日检查而破坏隔日成稿节奏。
- [ ] `SELECTED → WRITING` 由 `claim-writing` 原子完成，竞争任务不能重复领取。
- [ ] 选文、成稿、草稿批准、草稿回执、人工发表和统计快照可完成端到端状态流转。
- [ ] 每次事务提交后兼容 JSON 快照可重新生成，且不包含任何凭据。
- [ ] 每个新候选都含元数据级 `fulltext_access` 检查结果，且明确记录 `downloaded_content=false`。
- [ ] 推荐消息完整展示标题、期刊、日期、评分、推荐理由、方法焦点、DOI/PMID链接、全文与补充材料状态，不退化为仅列标题。
- [ ] 公开全文、需用户上传和状态未知三类结果均可进入五篇候选；科学评分不因可用性状态改变。
- [ ] 搜索阶段不请求、保存或缓存候选论文 PDF/HTML 正文。
- [ ] 选择 `USER_UPLOAD_REQUIRED` 或 `ACCESS_UNKNOWN` 论文后，`claim-writing` 返回 `awaiting_source_upload` 并给出周期专属输入目录和截止时间。
- [ ] 主论文 PDF 与补充材料只有在路径范围、文件类型、哈希、大小和论文身份全部核验后才能登记。
- [ ] 来源清单未登记或未达到 `SOURCE_VALIDATED` 时，正式文章工件不能写入状态库。
- [ ] 正式文章缺少 `evidence_level=FULLTEXT`、`fulltext_verified=true` 或来源清单时校验失败。
- [ ] 摘要级公开材料不足时进入 `EVIDENCE_BLOCKED`，不自动换文、不把摘要扩写为全文结论。

## API 测试

- [ ] 获取稳定凭据成功。
- [ ] API dry-run 在未配置封面或封面文件不存在时返回 `DRY_RUN_BLOCKED`，不得返回 `DRY_RUN_READY`。
- [ ] 上传正文图片和封面成功。
- [ ] 新增草稿成功，或明确记录无权限错误并切换备用通道。
- [ ] 没有调用发布或群发接口。
