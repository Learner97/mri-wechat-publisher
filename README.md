# MRI WeChat Publisher

This repository distributes the `mri-wechat-publisher` plugin for Codex through the `solel-mri-plugins` marketplace.

The plugin creates evidence-grounded Chinese MRI paper-and-method articles, validates scientific and publishing safety, renders WeChat-compatible HTML, and can save an explicitly approved draft without publishing it.

See the [plugin documentation](plugins/mri-wechat-publisher/README.md) for installation, dependencies, configuration, tests, and safety boundaries.

Runtime databases, credentials, source papers, generated drafts, and publisher full text are intentionally excluded from this repository.
